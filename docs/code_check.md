# 코드 점검: 도면·규정 대비 (2026-11-07)

대상: `ericar_driver` (main `d3b90d3`, 멘토 ORDA `answer.py` + 소민 차선 간단 버전). 기준: `2026Track 도면` DXF·PDF, `Autorace2026_규정집`(10/8 초안 수정본), 11/4 실차 측정.

근거 표기: **도면** = DXF 좌표·치수 / **실측** = 11/4 실차 측정 / **코드** = 코드 해석 (실차 미확인) / **시뮬** = 11/4 시뮬 시험

## 요약

- 멘토 시뮬 트랙은 같은 DXF(`cad_paths.json`)로 생성 → **노면 치수(차선·정지선·3차선·갈림길·주차 칸)는 시뮬과 실차 동일**
- 시뮬과 다른 것: 시설물 위치(표지판·장애물·라바콘, 시뮬 가정값), 차량 동역학, 센서 특성, 색·조명
- 실차 투입 전 필수: 라이다 후방 사각, 주차 기준선·조향, 차선 간단 버전의 마름모 처리 (라이다 0값·차선 색은 팀원이 실차에서 확인 후 수정)

## 🔴 실차 투입 전 필수

| # | 문제 | 내용 | 근거 | 담당 |
|---|---|---|---|---|
| 1 | ~~라이다 무효값~~ **해결 (PR #3)** | 실차 YDLidar가 한 프레임의 50~60%를 0으로 출력해 속도가 항상 0. `zero_is_no_return`으로 0을 무반사 처리 | 실차 확인 (유경) | 유경 |
| 2 | 라이다 후방 사각 | 실차 유효 각도 약 ±110°. PR #3 이후에도 섹터에 유효 점이 없으면 0(막힘) → 후방 섹터는 항상 0, 후진 시 정지, 주차 후진 단계 `fault: obstacle during parking` | 코드 + 실측 | 유경, 정윤 |

| 5 | 마름모 노면 표시 | 서행 구간·지그재그·상단 안쪽 차로에 마름모 + "천천히" 표시. 원본은 닫힌 도형을 차선에서 제거, 소민 간단 버전은 이 처리 삭제 → 마름모 테두리를 차선으로 오인 가능 | 도면 + 코드 | 혁준, 소민 |

## 🟡 확인·튜닝

- 회전 반경: 휠베이스 0.2 m, 조향 0.42 rad → 뒷바퀴 기준 약 0.45 m. 코너 안쪽 R0.6 m보다 작아 주행 가능 (계산)
- YOLO: CPU 2스레드, 320 px, 5 Hz 설정. Jetson GPU 실측 약 27 fps → GPU 사용 시 인식 거리·지연 개선 여지
- 신호등 3색 중 황색 처리 포함 (`traffic_yellow`). 방해 광고판 오검출은 실영상으로만 확인 가능
- 서행 구간 `slow_seconds` 14초 × 0.2 m/s = 약 2.8 m. 서행 구간 길이 실물 확인 필요
