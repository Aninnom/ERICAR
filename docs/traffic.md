# 신호등 작업 메모

## 현재 구현

- 모델 클래스: `traffic_red`, `traffic_yellow`, `traffic_green`
- 활성 구간: S4, 단독 시작 `start_stage:=traffic`
- 정지선 접근 → 앞바퀴 정지 확인 0.3초 → 녹색 확인 → 정지선 통과 후 미션 종료
- 녹색 연속 확인: 서로 다른 검출 영상 2장 (`detector.confirm_frames`)
- 면적 조건을 만족하는 빨강·노랑 첫 검출부터 녹색 허가 취소, 충돌 해소 후 녹색 재확인
- 신호 미검출 시 녹색 허가 없음. 기존 검출 끊김 8초·대기 60초 포기 정책 유지
- YOLO 면적 조건만으로 광고판 속 신호등 구별 불가. 실제 영상 검증·모델 보완 필요

## 검증

- 합성 시험: `python3 ericar_driver/test/test_traffic.py`
- Windows: `.venv/Scripts/python.exe -X utf8 ericar_driver/test/test_traffic.py`
- 합성 검출의 색 충돌·같은 영상 반복·미검출·정지 후 녹색 출발·통과 완료 확인
- 실제 YOLO 추론·광고판 구별·제동 거리 검증은 미완료
- 차에서 신호등과 광고판 동시 녹화 → 녹화 재생 → 시뮬 → 실차 순서 필요
