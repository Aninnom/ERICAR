## 2026-10-01 차선 검출은 scan line 방식

**결정**: 원본 영상에서 가로줄(1~3개)마다 좌·우 황색 차선 위치를 찾고, 그 가운데를 차로 중심으로 쓴다. BEV(조감도) + 슬라이딩 윈도우는 쓰지 않는다.

**이유**
- 실차 기간 대부분이 튜닝이라 디버깅이 쉬운 방법이 유리하다. scan line은 줄 하나만 보면 원인이 보인다
- 교육 자료·ORDA 자료와 같은 방식이라 팀원 모두 이해할 수 있다
- 줄이 고정이면 픽셀→미터 변환이 줄마다 상수 하나라 BEV 없이도 미터 출력이 된다

**알려진 약점과 대응**
- 급코너에서 차선이 줄을 벗어남 → 한쪽 차선 + 차로폭/2로 추정
- 휘어진 차선을 반대쪽으로 착각 → 이전 프레임의 차로 중심을 기준으로 좌우 분할
- 반응 타이밍 → 줄 2~3개 가중 평균, 비율은 YAML
- 차선이 화면 밖으로 완전히 나감 → 알고리즘 문제가 아님. 코너 감속(제어)·카메라 각도로 대응

**다시 고민하는 조건**: 2D 시뮬 또는 실차에서 급코너(작년 기준 R0.67 m)를 위 대응으로도 못 돌 때 BEV 검토. 로컬 실험 코드 `LaneDetect/` 재사용 가능.

**영향 범위**: `autorace_camera` 내부만. 출력 형식(미터 단위 목표점·횡오차·검출 여부)은 그대로라 다른 패키지는 바뀌지 않는다.
