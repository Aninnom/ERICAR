## 2026-10-01 차선 검출: scan line 방식으로 결정

**내용**: 원본 영상의 가로줄(1~3개)마다 좌·우 황색 차선 위치 검출, 그 가운데를 차로 중심으로 사용. BEV(조감도) + 슬라이딩 윈도우는 미사용.

**이유**
- 실차 기간 대부분이 튜닝 → 디버깅 쉬운 방법이 유리. scan line은 줄 하나만 보면 원인 파악 가능
- 교육 자료·ORDA 자료와 같은 방식 → 팀원 전원 이해 가능
- 줄 위치 고정 시 픽셀→미터 변환이 줄마다 상수 하나 → BEV 없이 미터 출력 가능

**알려진 약점과 대응**
- 급코너에서 차선이 줄 밖으로 이탈 → 한쪽 차선 + 차로폭/2로 추정
- 휘어진 차선을 반대쪽 차선으로 오인 → 이전 프레임 차로 중심 기준으로 좌우 분할
- 반응 타이밍 → 줄 2~3개 가중 평균, 비율은 YAML
- 차선이 화면 밖으로 완전히 이탈 → 알고리즘 문제 아님. 코너 감속(제어)·카메라 각도로 대응

**재검토 조건**: 2D 시뮬 또는 실차에서 급코너(작년 기준 R0.67 m)를 위 대응으로도 통과 못 할 때 BEV 검토. 로컬 실험 코드 `LaneDetect/` 재사용 가능.

**영향 범위**: `autorace_camera` 내부만. 출력 형식(미터 단위 목표점·횡오차·검출 여부) 동일 → 다른 패키지 영향 없음.
