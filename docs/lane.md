# 차선 인식·주행 (혁준·소민)

`lane_vision.py`(인식) + `lane_driving.py`(조향·속도). 최종 갱신 2026-11-08 (혁준)

## 현재 상태

- 노란 차선: 1번 코너 0.2·0.3·0.4 m/s 실차 통과 (앞바퀴 선 안 밟음). PR #8 (코너), #9 (정리)
- 흰색 노면 표시 검출 없음 → 아래 "흰색 작업"
- 나머지 세 코너·전체 1바퀴 실차 미확인

## 처리 순서 (`LaneVision.analyze`)

1. 색: HSV에서 노란색(`yellow_min/max`)만 남김
2. BEV: 카메라 높이·기울기(`robot.yaml`)로 바닥을 위에서 본 그림으로 변환. 뒷축 기준 앞 0.6~1.7 m, 좌우 2.4 m, 480×420 px
3. 가로선 분리: 가로로 긴 페인트(`horizontal`)는 정지선 검출용, 나머지(`lane_mask`)는 차선용
4. 차선 찾기: 아래쪽 히스토그램으로 좌/우 시작점 → sliding window → 선마다 2차식
5. 좌우 판단 (`label_sides`)
   - 좌우 창이 같은 픽셀 30% 넘게 공유하면 같은 선 → 하나로
   - 한 선이면 직전 프레임 선의 가까운 끝(실제 픽셀)과 가까운 쪽 이름 이어받음 (`memory_frames`)
   - 이력 없으면 가까운 끝 좌우 위치로 판단
6. 목표점 (`pursuit_target`): 보이는 선 점마다 진행 방향 법선으로 차로 폭 절반 안쪽 → 중앙선 점들 → 뒷축에서 `pursuit_distance`(0.65 m)인 점. 두 선이면 평균
   - 차로 폭: 직선 0.52 m, 선 곡률 0.8~1.4 /m 구간에서 코너 폭 0.77 m로 보간 (도면)
7. 정지선 (`find_stop_line`): `horizontal`에서 차로 폭 대부분을 가로지르는 줄 → 앞바퀴 기준 거리 `stop_distance`

조향 (`LaneDriving`): 목표점 있으면 pure pursuit만, 없으면 lookahead 오차 PID. 속도 `base_speed`(0.4)에서 조향 클수록 감속 (코너 약 0.2 m/s)

## 왜 이렇게 됐나 (11/8 실차 5회 시행착오)

- 고정 lookahead(0.9 m) 지점의 차로 중앙은 R0.6 코너에서 존재하지 않음 → 2차식 외삽·오차 급변
- 2차식 곡률 앞먹임은 직선+원호 혼합 구간에서 과대 → 일찍 꺾음 → 제거
- 가장 가까운 선 점의 수직 발을 목표로 하면 차 방향이 어긋날 때 되돌리는 힘 없음 → 진행 방향으로 일정 거리 앞의 점
- 곡선 비교·곡선 연장 끝 기준 좌우 판단은 맞춤 오차로 오판 → 실제 픽셀 기준
- 코너에서 어느 선이 남는지는 차 자세에 따라 다름 (중앙 주행: 바깥 선 / 안쪽으로 파고듦: 안쪽 선) → 위치 규칙보다 연속성
- 차선 놓치면 `previous_center` 초기화 (안 하면 엉뚱한 기준 주변만 찾다 영영 못 찾음)

## 트랙 도면 사실 (`2026 국민대 LIMO 트랙 도면.zip`, DXF 1 단위 = 30 mm)

- 선 중심 간격 0.52 m (규정 표기 550 아님)
- 코너: 안쪽 선 R590, 바깥 선 R660, 중심이 (0.5, 0.5) m 어긋난 비동심 → 코너 차로 폭 0.76~0.78 m
- 바깥 선은 코너 직전 R1400 역방향 원호로 먼저 바깥쪽으로 휨 → 코너 진입 직전 바깥 선만 보면 직진·왼쪽 신호
- 미션 위치 좌표표 `docs/code_check.md`

## 흰색 작업 (소민 담당, 11/9~)

트랙: 차선 = 노랑, 정지선·횡단보도·마름모·"천천히" = 흰색. 지금은 흰 마스크 없음 → 정지선 항상 미검출
- 보행자: 표지판 + 정지선이 보여야 접근 시작 (`pedestrian_require_line`) → 지금은 통과해버림
- 신호등: 정지선 없으면 0.13 m/s → 2초 뒤 정지 → 15초 뒤 실패
- 주차 정렬도 정지선 거리 사용

할 일 (제안 순서)
1. 흰 마스크 추가: `analyze`에서 노란 마스크와 별도로 생성 → BEV. 파라미터 `params.py` lane 구역 `white_min/max` (이름 비어 있음). 예전 주석 범위 `[0,0,165]~[179,85,255]`, 노출 300 기준 실측 필요
2. 정지선을 흰 마스크 가로선으로: `find_stop_line` 입력만 교체. 차선(`lane_mask`)은 노란 마스크 그대로 → 차선 주행 영향 없음
3. 횡단보도: 도면상 두 곳 (신호등 앞 상단 안쪽, 보행자 우측). 줄무늬를 정지선으로 오인하지 않는지 확인. `driver.py`의 `line_match_tolerance`(0.1 m)가 먼 줄무늬로 갈아타기 방지
4. 마름모·"천천히": 노란 마스크에 안 섞이는지, 흰 가로선 검출(최소 길이 0.32 m·최대 두께 0.13 m)에 안 걸리는지
5. 디버그 화면(`tools/debug_view.py`)에 흰 마스크 표시 추가하면 작업 편함

회귀 시나리오는 정지선을 노랑으로 그림 → 흰 검출로 바꾸면 깨짐. 혁준이 시나리오 정지선 흰색 수정·기준값 재생성 예정 (`white_min/max` 키 이름 맞춰 줄 것)

흰 표시가 찍힌 녹화 (차 `~/bags/`): `corner_1108_2144_v04`, `corner_1108_2142_v03`, `corner_1108_1936_k17` (1번 코너 뒤 지그재그 구간 마름모·"천천히"). 정지선·횡단보도 정면 녹화는 아직 없음 → 새로 녹화 필요

## 검증 순서 (추측으로 고치지 말 것)

1. 녹화로 문제 장면 확인: `tools/bag_timeline.py`(시계열) → `tools/bag_frames.py`(해당 시각 영상)
2. 코드 수정 후 같은 녹화로 전후 비교: `tools/replay_bag.py` (main → before.csv, 내 브랜치 → after.csv)
3. 바뀐 영역 시험 파일만 실행 (`python3 -m pytest test/<파일>`, 차에서). 회귀 시험은 11/19 삭제
4. 실차: `bringup.launch.py record:=true`로 녹화 남기며 시험 → 다시 1번

## 주의

- `label_sides`·`pursuit_target`·`previous_center`·`previous_anchors`는 코너 통과 핵심. 고치면 녹화 재생으로 조향 동일 확인
- `center_px`(lookahead 0.9 m 중앙)는 정지선 탐색 범위 기준. 코너에서는 부정확
- `params.py` lane 구역은 혁준·소민 공유. 바꾸면 서로 알림
